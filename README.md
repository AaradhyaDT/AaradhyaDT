## About

I'm a final-year Electronics, Communication & Information Engineering student at **Kathmandu Engineering College (IOE, Tribhuvan University)**, based in Kathmandu, Nepal (graduating January 2027). **Seeking AI/ML engineering opportunities.**

I build model-evaluation pipelines, AI workflow tools, and embedded ML software. I use AI to accelerate development, then turn recurring work into reusable tools and deterministic checks — reducing the need to solve the same task in another prompt.

- **Model Evaluation & Fairness**: Auditing demographic performance gaps in facial-analysis models ([BiasAperture](https://github.com/AaradhyaDT/BiasAperture)) across 126 demographic intersections with BCa bootstrap confidence intervals.
- **Embedded Edge AI**: Leading embedded & ML architecture for [SPARK](https://github.com/AaradhyaDT/SPARK) — a sub-20KB INT8 CNN running at 200 Hz ISR sampling on ESP32-S3 FreeRTOS for wearable fall detection.
- **AI Workflow Infrastructure**: Author of [Fleet-Orchestrator](https://github.com/Aaradhya-Dev-Tamrakar/Fleet-Orchestrator) and [Agent-Customization-Sync](https://github.com/Aaradhya-Dev-Tamrakar/Agent-Customization-Sync) to coordinate multi-worker swarms and eliminate configuration drift across IDEs.

## How I Build

> *Decide what needs model reasoning, automate repeatable steps, and make the result inspectable.*

- **Use models deliberately**: Rely on models for reasoning, architecture, and synthesis; use deterministic scripts and tests for repeatable transforms, parsing, and execution.
- **Eliminate recurring prompt debt**: Build reusable interfaces, FastMCP servers, and configuration synchronization to avoid re-solving the same problem every session.
- **Keep evidence in context**: Strictly distinguish implemented code, simulations, benchmark results, and hardware measurements with reproducible evaluation criteria.
