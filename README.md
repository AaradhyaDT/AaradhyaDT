## About

I build systems at the boundary of **physical sensing, embedded Edge AI, OS-level execution, and agentic infrastructure** — with a relentless focus on getting models out of notebooks into production hardware and reliable software pipelines.

Undergraduate Electronics, Communication & Information Engineer (BEI) at **Kathmandu Engineering College (IOE, Tribhuvan University)**, graduating January 2027. Primary focus on **Edge AI, real-time embedded firmware, Model Context Protocol (FastMCP) tooling, and deterministic verification**.
